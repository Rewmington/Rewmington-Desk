# 本周与每日任务

> 这份是唯一会**每周改动**的文档。改的是仓库里 `src/content/notes/weekly-plan.md` 这一份，push 之后手机上刷新就是新的。
> **2026-10-10 顺延**：10/05–10/11 这周因为考试整周作废，不做、不补。下面的周次全部往后推一周，并改成**周一起算**；W1 从 10/12 开始。

## 一、主线永远只有三条

| 主线 | 每天最低量 | 过关判据 |
|---|---|---|
| 算法 | **2 题**，不许降到 1 | 中等题 25 分钟内做出，能讲复杂度 |
| 理论 | 一个模块推进 1~2 节 | 合上资料录音讲 5 分钟，不卡（讲义 01–04 末尾各有三道题，那就是判据） |
| 项目 | 一个晚上，或一个具体方法 | 能被追问三层不崩 |

简历上只有第三条能写东西，第一条决定你能不能进面，第二条决定面试会不会被问穿。三条缺一条都不成立。

## 二、每周固定动作

- 周一到周五：算法 2 题（固定时段，别"有空再做"）
- 工作日：2 个晚上给本周理论模块，1 个晚上给项目
- 周末：半天推项目，半天复盘 + 回填自测表
- 睡前 5 分钟：有坑就写进踩坑记录，没有就不写

## 五、每周计划

| 主线 | 这一周（W1）用什么 | 下一周（W2）排什么 |
|---|---|---|
| 算法 | 2 题/天，按题型顺序往后走 | 2 题/天，本周起进入链表 |
| 理论 | MySQL：讲义 01（索引）+ **讲义 03（事务与 MVCC）** | 并发：讲义 02（线程池那一套） |

**讲义从哪来**：`study/dist/`，编号就是阅读顺序，**七篇全部写完了**：01 MySQL 索引与 B+ 树、02 Java 并发与线程池、03 MySQL 事务与 MVCC、04 Redis 持久化主从哨兵与 Cluster、05 Redis 缓存三兄弟/分布式锁/缓存一致性、06 消息队列、07 MySQL 主从复制与分库分表。每篇末尾都有三道自测题和一节「核对清单」，清单分成 **✅ 已核（有官方出处）** 和 **⚠️ 留空（我没核实）** 两类 —— **留空那些必须自己去查再写回笔记**，没核实的数字别写进简历。

**顺延只挪日期，不砍内容。**
