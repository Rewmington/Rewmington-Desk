# 我要学什么（2028 届 · Java 后端 + AI 应用）

更新：2026-10-02 ｜ 配比：后端 70% / AI 应用 30% ｜ 每天 2 道算法题不断

## 第一段：现在 → 2026 年 12 月中（投寒假实习前）

### MySQL（把"会用"变成"知道为什么"）

- [ ] B+ 树结构，以及它为什么适合存磁盘上的数据
- [ ] 聚簇索引、二级索引、回表
- [ ] 联合索引与最左前缀
- [ ] 索引失效的几种写法（函数包列、隐式类型转换、前缀通配）
- [ ] 事务四大性质，重做日志与回滚日志各保证什么
- [ ] 四种隔离级别，可重复读下的 MVCC 怎么工作
- [ ] `EXPLAIN` 执行计划，慢查询定位流程
- [ ] 死锁怎么产生、怎么排查

> 过关标准：白板画出"一条 SQL 从客户端发过来到返回结果"的完整链路。

### Redis（把"能缓存"变成"知道坏在哪"）

- [ ] 单线程模型为什么快
- [ ] 五种基本类型及其底层结构
- [ ] 过期键删除策略、内存淘汰策略
- [ ] RDB 与 AOF
- [ ] 穿透、击穿、雪崩：成因与各自治法的副作用
- [ ] 分布式锁：SETNX、超时时间、误删、可重入
- [ ] 缓存与数据库的一致性方案（先删还是先改、延迟双删）
- [ ] 用 Redis 做计数器和排行榜

> 过关标准：给一个 500 次读/秒 的商品详情接口，说出缓存方案**和它的缺陷**。

### Java 并发（从零开始）

- [ ] 线程的生命周期与状态转换
- [ ] `synchronized` 锁的是什么对象，锁升级大致过程
- [ ] `volatile` 保证什么、不保证什么
- [ ] `ReentrantLock`：可重入、公平、条件变量
- [ ] 线程池七个参数、任务提交流程、拒绝策略
- [ ] `ThreadLocal` 原理与内存泄漏
- [ ] `CAS` 与原子类、ABA 问题
- [ ] `CountDownLatch` / `Semaphore` / `CyclicBarrier` 各解决什么
- [ ] 死锁的四个必要条件
- [ ] （往后放）AQS 源码

> 过关标准：说清自己项目里线程池参数为什么这么设，设大设小分别什么后果。

### 数据结构与算法（目标 150 题）

- [ ] 数组、哈希表
- [ ] 双指针、滑动窗口
- [ ] 二分查找及其边界写法
- [ ] 链表（反转、快慢指针、合并）
- [ ] 栈与队列（单调栈先了解）
- [ ] 二叉树遍历（前中后序、层序）
- [ ] BFS / DFS
- [ ] （下一段）回溯、动态规划、贪心

> 过关标准：中等题 25 分钟内做出，能讲时间空间复杂度。

### 项目：本地文档知识库问答（Spring AI + pgvector）

- [ ] pgvector 建表与向量列、近似最近邻查询语法
- [ ] 文档读取与切分策略（按长度、按段落、重叠窗口）
- [ ] 批量向量化入库，**启动时只查不重算**
- [ ] 检索 top-K 结果拼进提示词，让模型基于它回答
- [ ] 检索不到时明确拒答
- [ ] SSE 流式返回给前端
- [ ] Vue 前端接上，能完整演示
- [ ] 记录每次问答的 token 消耗和延迟

> 过关标准：能被追问三层不崩 —— 为什么用 pgvector 不用云服务 → 检索不准怎么办 → 文档更新了向量怎么办。
